Day 45 — useState & Events

Understand state (useState) and DOM/event handling with concise React examples and interactive playgrounds.

Concept overview

useState is the React hook to add local state to function components. Events (onClick, onChange, onSubmit) trigger updates. Key ideas:

  • State is local to a component and persists between renders.
  • Never mutate state directly — use the setter returned by useState.
  • Event handlers receive an event object; preventDefault to stop native form submit.

React snippets

Counter (useState)

import React from 'react';

export default function Counter() {
  const [count, setCount] = React.useState(0);

  return (
    <div>
      <h2>{count}</h2>
      <button onClick={() => setCount(c => c + 1)}>Increment</button>
      <button onClick={() => setCount(0)}>Reset</button>
    </div>
  );
}

Controlled input (onChange)

function NameInput() {
  const [name, setName] = React.useState('');

  return (
    <input value={name} onChange={e => setName(e.target.value)} />
  );
}
