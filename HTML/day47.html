Day 47 — Routing with React Router

How routes, links and params work. Quickstart, core concepts and a small interactive demo.

Quickstart

  • Install: npm install react-router-dom@6
  • Wrap app: <BrowserRouter>...</BrowserRouter>
  • Define routes using <Routes> + <Route path="..." element={...} />

Core concepts (kid-style)

  • Router — keeps track of the URL and chooses which component to show.
  • Route — one mapping from URL path → UI.
  • Link — clickable element that changes URL without full page reload.
  • useParams — read params from the URL (like an id).
  • useNavigate — jump to another route programmatically.

Example App (App.jsx)

import { BrowserRouter, Routes, Route, Link, useParams } from 'react-router-dom';

function Home() { return <h2>Home</h2>; }
function About() { return <h2>About</h2>; }
function User() {
  const { id } = useParams();
  return <h2>User {id}</h2>;
}

export default function App() {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Home</Link>
        <Link to="/about">About</Link>
        <Link to="/user/1">User 1</Link>
      </nav>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
        <Route path="/user/:id" element={<User />} />
      </Routes>
    </BrowserRouter>
  );
}

Tips

  1. Prefer routes for different pages/views — keep components small.
  2. Use nested routes for layouts (sidebars, dashboards).
  3. Protect routes (auth) with wrapper components.
