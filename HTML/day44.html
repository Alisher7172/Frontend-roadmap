Day 44 — React Components, JSX & Props

Components are the building blocks. Learn JSX, props, patterns and practical tips — interactive playground below.

What is a Component?

Components are reusable, isolated UI pieces. They can be function components or class components (use functions + hooks for modern React).

  • Single Responsibility — one job per component
  • Small & composable — build complex UIs by composing small components
  • Stateless vs stateful — lift state up when needed

JSX Primer

JSX looks like HTML but is JavaScript. You can embed expressions with {`{}`}, use conditional rendering and spread props.

function Hello({ name }) {
  return <h1>Hello, {name}!</h1>;
}

Props — Data in

Props are read-only inputs to components. Use them to pass strings, objects, functions and children.

  • <Card title="Hi" /> — primitive props
  • <List items={items} /> — pass arrays/objects
  • <Button onClick={handle} /> — pass callbacks
  • Children: <Modal>content</Modal> — compose UI

Tip: keep props minimal; prefer controlled components for forms.

Stateless Button

          
function Button({ children, onClick }) {
  return <button onClick={onClick}>{children}</button>;
}
          

        

        

          
Controlled Input

          
function NameInput() {
  const [name, setName] = React.useState('');
  return <input value={name} onChange={e => setName(e.target.value)} />;
}
