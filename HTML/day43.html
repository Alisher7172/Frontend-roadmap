Day 43 — Intro to ReactJS

What to learn first, quickstart commands, core concepts and a small example

React is a component-based library for building UIs. Start with components, JSX, props, state, and hooks (useState/useEffect). Below are quick commands, core concepts and a runnable example snippet you can copy.

Quickstart

  • npx create-react-app my-app — official CRA starter
  • npm create vite@latest my-app -- --template react — fast Vite starter
  • Run: cd my-app then npm install and npm start (CRA) or npm run dev (Vite)

Core concepts

  • JSX — HTML-like syntax in JS
  • Components — functions that return UI
  • Props — input to components
  • State — component-local mutable data (useState)
  • Effects — side effects & data fetching (useEffect)
  • Routing — client-side navigation (react-router)

Small example

Copy the snippet and paste in a new create-react-app / Vite project (replace App.jsx contents).

function Counter() {
  const [count, setCount] = React.useState(0);
  return (
    <div>
      <h2>Count: {count}</h2>
      <button onClick={() => setCount(c => c + 1)}>Increment</button>
    </div>
  );
}

export default function App() {
  return <Counter />;
}
