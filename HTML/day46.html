Day 46 — useEffect & Lifecycle

Simple, friendly explanations of mounting, updating, cleanup and effects + interactive demos

What is a "lifecycle"?

Think of a component like a toy robot:

  • Mount — the robot turns on (we set it up).
  • Update — we press buttons and it changes (props/state change).
  • Unmount — we turn it off and put it away (clean up).

What is useEffect?

useEffect is like telling the robot to do things when it turns on, when something changes, or just before it turns off. It lets you run code at the right time and clean up after it.

Simple rules

  1. Put setup code (timers, network) inside useEffect so it runs when needed.
  2. Return a cleanup function from useEffect to stop timers or cancel things when the component goes away.
  3. Use the dependency array: [] runs once at mount, [x] runs when x changes, no array runs after every render.
